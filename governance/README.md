# Governance

治理层定义项目工程能力管理器要守住的质量边界。它回答“项目必须满足什么”，而 `workflow/` 回答“什么时候调用什么能力”。

## 四个治理面

- [architecture/](architecture/)：系统结构、模块边界、分层和架构决策。
- [design/](design/)：接口、职责、所有权和数据流契约。
- [review/](review/)：代码、模块、依赖和架构审查。
- [../policies/](../policies/)：语言、框架、复杂度、错误处理和构建相关策略。

治理规则应尽量表达可验证的约束；流程编排、来源选择和上游内容不放在这里。
