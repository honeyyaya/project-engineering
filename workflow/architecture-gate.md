# Architecture Gate

确认变更落在哪个模块和层，依赖方向、线程/进程边界、所有权、数据流、接口稳定性和失败路径是否明确。

重大变化额外回答：如果今天从零开始，是否还会选当前架构？继续扩展、局部重构和替换/迁移的摩擦分别是什么？哪些代码、数据和测试可以保留？

**通过条件**：目标结构有代码或构建证据，替代方案和迁移/回滚条件已记录，必要时有 ADR。

新建项目尚未有代码时，先用目标模块图、接口和工具链事实审查设计，明确标为 planned；实现后再用实际构建和代码验证，不把设计审查视作构建通过。各阶段还需按 [风险发现流程](risk-discovery.md) 提交适用检查与证据。
